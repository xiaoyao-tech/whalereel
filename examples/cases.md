# 四个案例：一句话 → 一支片

> 这四支片子是鲸片 v0.2 的“验收样片”，也是四种风格的用法说明。
> 每支都按同一套流程做：**一句话 → 选风格 → 搜资料 → 写脚本 → 写场景 → 渲染 → 验收**。
> 案例片在仓库的 `renders/cases/`（安装版只带文档，不带视频）；完整版在各自的项目目录里（见每节末尾）。

## 1. 朱元璋 · 档案卷宗（3 集，共 130 秒）

**一句话**

> 做一条朱元璋治国的知识科普，分 3 集、每集 45 秒，16:9，要旁白和字幕，结尾落在“恐惧不能代替制度”。

**为什么选档案卷宗**

稿子的开场是一串档案式的事实：年份、地点、谁死了、谁没给地；中段的核心物件又全是纸——黄册、鱼鳞图册、名册、祖训、遗诏。所以不该“演”明朝，该“查”明朝。

**资料（先查再做）**

| 说法 | 来源 | 用法 |
|---|---|---|
| 洪武十三年（1380）废中书省、罢丞相，六部直对皇帝 | 《明太祖实录》《明史·职官志》 | 第 1 集 |
| 八天 1660 件奏章、3391 件事 | 《明太祖实录》洪武十七年九月十四至二十一日 | 第 2 集 |
| 黄册（1381）、里甲、鱼鳞图册（1387） | 《明史·食货志》 | 第 1 集 |
| 洪武二十六年 1065 万户 / 6054 万口 | 《明太祖实录》 | 第 1 集，片上标“洪武二十六年·户部” |

**结构**

| 集 | 时长 | 内容 |
|---|---:|---|
| 第 0 集 | 47.8s | 即位 → 荒年 → 户籍 → 度牒 → 名字 → 治国三件事 → 版籍 |
| 第 1 集 | 40.8s | 户等与里甲（110 户网格、连坐）→ 罢丞相 |
| 第 2 集 | 41.6s | 奏章（八天 1660 件）→ 四大案 → 俸禄悖论 |

**签名瞬间**：涂黑条从左侧滑入，盖住“父 / 母 / 长兄”三行，标“无载”；结尾落印时全屏抖一下。

**踩过的坑**

- 第一版用木刻版画做了 15 秒：质感对，但没有旁白，信息讲不出来 → 换成档案卷宗。
- 旁白是 TTS，偏平；正式片建议真人配音。
- 字幕烧死在画面上，二次剪辑会带着走 → 要转发就出无字幕版。

**可复用提示语**

```
用 whalereel 的档案卷宗风格，做一条 <人物/事件> 的知识科普，45 秒，16:9。
要旁白 + 烧录字幕；先给我 6 拍脚本和资料出处，我确认后再写场景。
结尾落在一句判断上，全片只允许这一句。
```

**成片**：`film-episodes/ep0.mp4`、`ep1.mp4`、`ep2.mp4`（本项目案例，1080p / 24fps / 有声）

## 2. 庐州月 · 钢笔淡彩（60 秒，无旁白）

**一句话**

> 用钢笔淡彩做一支 60 秒短片，拍《庐州月》的意象：一个人三月夜里回到故乡，桥还在，月光还在，只有记忆里的人褪回了线稿。

**为什么选钢笔淡彩**

这是一个“情绪 + 地点 + 时间”的题，没有数据、没有流程、也不需要讲道理。钢笔淡彩的语法正好：线负责记忆，颜色负责此刻；颜色退去，就是人走了。

**资料**

- 一处具体地点：石桥、白墙黑瓦、乌篷船、河面——能画出来的那种。
- 一段可压缩的时间：一夜。
- 一个颜色事件：一盏红灯笼。它经过哪里，哪里才有颜色。
- **版权**：不引用许嵩原曲的旋律、编曲、歌词；配乐是原创五声音阶（古筝、箫、低音弦），只借意象。

**结构**

| 时间 | 画面 |
|---|---|
| 0–8s | 空白纸角，笔尖写下“三月·庐州·夜”，一条横线拉开河面 |
| 8–26s | 白墙黑瓦石桥从线里长出来，红灯笼带来第一块颜色 |
| 26–42s | 灯笼穿过桥洞，记忆里的人显影；颜色第一次为“人”亮起 |
| 42–52s | 风起，颜色从她身上退去，只剩灯笼和月亮 |
| 52–60s | 人走下桥，走进纸的下边距；镜头拉回整页，标题写出 |

**签名瞬间**：颜色只跟着灯笼走；她身上的颜色先退。

**踩过的坑**

- 最初想做 4 分钟 MV：没有合法音源，渲染也撑不住 → 砍到 60 秒，原创配乐。
- 人物是 2D 剪影，近景能看出袖口简化；不要给她五官。
- 整体偏淡，手机小屏 + 亮环境会吃亏。

**可复用提示语**

```
用 whalereel 的钢笔淡彩风格，做一条 60 秒短片，主题是 <地点 + 一段情绪>。
无旁白；原创配乐；只借 <作品> 的意象，不引原文。
要一个“颜色事件”：什么东西经过，哪里才有颜色。
```

**成片**：`luzhou-moon/luzhou-moon.mp4`（1080p / 24fps / −13.9 LUFS）

## 3. 北京 · 白模投影（120 秒）

**一句话**

> 用白模投影做一条 120 秒的北京城市介绍，从地形、中轴、老城讲到 CBD 和双奥；要女声旁白、字幕烧进画面，每个数字都要有出处。

**为什么选白模投影**

这是“城市 + 数据 + 时间”的题。白模投影的规矩是：模型是真实几何，数据是光。它不靠形容词，靠 11,308 栋房子和 2,183.2 万人。

**资料**

| 数据 | 值 | 来源 |
|---|---|---|
| 面积 | 16,410 km² | 北京市规自委 |
| 中轴 | 7.8 km / 15 处 / 2024 世界遗产 | 国家文物局 |
| 常住人口 | 2,183.2 万（2024） | 北京市统计公报 |
| 中国尊 | 528 m | china.org.cn |
| 双奥之城 | 2008 夏奥 / 2022 冬奥 | 国家体育总局 |
| 建筑轮廓 | 老城 11,308 栋 / CBD 2,118 栋 | OpenStreetMap（ODbL） |
| 地形 | SRTM / GMTED，240×200，垂直夸张约 10× | Mapzen Terrarium（CC BY 4.0） |

**结构**（六章）

地形 → 三千年（周口店/琉璃河）→ 八百年（金中都/元大都/中轴）→ 棋盘与胡同 → 今天（十六区/环路/CBD）→ 双奥 → 新城 → 收尾。

**签名瞬间**：说到某个地点，那个点向外发一圈波光；太阳层用真实方位与长影子扫过。

**踩过的坑**

- 第一版 30 秒只有画面没有解说 → 加到 120 秒，写旁白。
- 第一版是 2.5D 示意 → 换成 Three.js + 真实 OSM footprint。
- 输出只有 720p；要上大屏得重渲 1080p。
- 鸟巢/水立方是手工白模，不是测绘，片中标了“双奥”。

**可复用提示语**

```
用 whalereel 的白模投影风格，做一条 <城市> 的介绍，120 秒，16:9。
要真实建筑轮廓和地形数据，每个上屏数字给出来源；女声旁白，字幕烧进画面。
先给我六章结构和数据清单，我确认后再写场景。
```

**成片**：`whalereel/renders/v5/beijing-120s.mp4`（1280×720 / 24fps / 有声）

## 4. 潭柘寺 · 立体纸雕（45 秒，项目自带示例）

**一句话**

> 做一条潭柘寺的景区介绍，45 秒，16:9，给公众号读者看，结尾露出“先有潭柘寺，后有北京城”。

**为什么选立体纸雕**

景区介绍要“空间感 + 温度”，纸雕的层深和暖光最合适；水墨适合做 30 秒氛围片，但讲不了沿革。

**资料（先核对，再上屏）**

- “先有潭柘寺，后有北京城”是**民间说法**，片中作为引语，不写“据史料记载”。
- 潭柘寺始建于西晋；常见说法为公元 307 年，发布前以寺院官方资料为准。
- “帝王树”是银杏，树龄常见说法 1400 多年；片中用“一千多年”更稳。
- 大雄宝殿、流杯亭、石鱼、后山都真实存在；不要编“某年某月”。

**结构（45s）**

| 时间 | 画面 | 旁白 |
|---|---|---|
| 0–5s | 黑场，火柴划亮，灯箱亮起 | 无 |
| 5–12s | 最前层山门剪影，缓慢推近 | 北京城西，有一座比城更老的寺 |
| 12–22s | 纸层分开，露出大雄宝殿和帝王树 | 西晋至今，山门开了 1700 多年 |
| 22–32s | 光从晨转暮，小人沿石阶走 | 一棵银杏，看过无数个秋天 |
| 32–40s | 拉远，整个盒子可见 | 山还是那座山，寺还是那座寺 |
| 40–45s | 朱印落下，定格 | 无 |

**签名瞬间**：12–22s 镜头穿过山门，进入第二层。

**踩过的坑**

- 纸雕的人只有 30px，像一根小棍——不要让人抢戏。
- 水墨版把“寺”画成了亭子；纸雕版的屋顶必须有起翘和檐口。
- 8 秒能证明风格，45 秒才讲故事；先做 10 秒测试片再扩。

**可复用提示语**

```
用 whalereel 的立体纸雕风格，做一条 <景区> 的介绍，45 秒，16:9。
结尾露出“<一句地方说法>”，并注明这是民间说法。
先给我 6 拍脚本，确认后再写场景。
```

**成片**：`renders/01-tanzhe-45s.mp4`（45 秒，有声）；工程 `output/tanzhe-45s/`（brief / script / sources / qa / 配乐）

## 四种风格怎么选（速查）

| 你手上的素材 | 选 | 因为 |
|---|---|---|
| 史料、档案、时间线 | 档案卷宗 | 它能把“纸”变成画面 |
| 一处地点、一段情绪 | 钢笔淡彩 | 它允许没有旁白 |
| 真实数据、地图、人口 | 白模投影 | 它靠数字立身 |
| 景区、古建、地标 | 立体纸雕 | 它给空间和温度 |
| 一个概念、一条流程 | 白板讲解 | 它能边画边讲 |
| 山水、诗词、氛围 | 水墨 | 它敢留白 |

> 一句话：**先看观众看完要做什么，再看你手上有什么。**
