# 北京：山与平原之间的三千年

**100 秒城市纪录片 · 文案 / 分镜 / 数据**

> 不是“北京老城”，是北京这座城。
> 老城只占第 3–4 章；开头是地形，结尾是整座城。
> 旁白按 Tingting、rate 180 实测 93.4 秒；留 6.6 秒气口与落款，总长 100 秒。

## 视觉结构：四个尺度，不是一个大模型

| 尺度 | 用什么 | 说明 |
|---|---|---|
| 市域 | 3D 地形 relief：西山、燕山、华北平原、永定河/潮白河 | 16,410 km² 的舞台；地形为示意，不是测绘 |
| 老城 | 11,308 栋真实 OSM footprint（已有） | 金中都/元大都/明清/中轴/胡同；只占第 3–4 章 |
| CBD | 从北京 OSM extract 里另切 CBD bbox，建第二个 3D 模型 | 中国尊 528m、CBD 楼群；真实 footprint |
| 收尾 | 地形 + 城市灯光 + 数据图层 | 把四个尺度收在一张图上 |

**为什么不是一个模型**：16,410 km² 全域做到逐栋建筑，数据量和渲染都不现实；纪录片用“地形—老城—CBD—全域”四个尺度切换，既讲全，又有细节。
