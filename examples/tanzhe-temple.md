# 示例：潭柘寺，三种拍法

> 一句话 brief：做一条潭柘寺的景区介绍，45 秒，16:9，给公众号读者看，结尾露出“先有潭柘寺，后有北京城”。

## 0. 先核对事实

- “先有潭柘寺，后有北京城”是**民间说法**，不是严格史实。片中作为引语出现，不要写成“据史料记载”。
- 潭柘寺始建于西晋；常见说法为公元 307 年，发布前以寺院官方资料为准。
- “帝王树”是银杏，树龄常见说法为 1400 多年；不同来源有差异，片中用“一千多年”更稳。
- 大雄宝殿、流杯亭、石鱼、后山都是真实存在的点位；不要编造“某年某月”的细节。

## 1. 风格选择

- **首选：立体纸雕。** 景区介绍需要“空间感 + 温度”，纸雕的层深和暖光最合适。
- **备选：水墨。** 适合做 30 秒氛围片，不适合讲历史沿革。
- **备选：俯视立体。** 适合做导览片，信息清楚，但情绪弱。

---

## 2. 立体纸雕版（45s）

### 分镜

| 时间 | 画面 | 字幕 | 旁白 | 声音 |
|---|---|---|---|---|
| 0–5s | 黑场，火柴划亮，纸雕灯箱亮起 | 潭柘寺 | 无 | 划火柴、灯丝嗡鸣 |
| 5–12s | 最前层山门剪影，缓慢推近 | 先有潭柘寺 | 北京城西，有一座比城更老的寺。 | 纸响 |
| 12–22s | 纸层分开，露出大雄宝殿和帝王树 | 后有北京城 | 西晋至今，山门开了 1700 多年。 | 低音铺底 |
| 22–32s | 光从晨转暮，小人沿石阶走 | 帝王树 | 一棵银杏，看过无数个秋天。 | 脚步、鸟鸣 |
| 32–40s | 拉远，整个盒子可见 | 深山藏古寺 | 山还是那座山，寺还是那座寺。 | 音乐起 |
| 40–45s | 朱印落下，定格 | 潭柘寺 | 无 | 印章闷响 |

### 旁白全文（约 60 字）

> 北京城西，有一座比城更老的寺。
> 西晋至今，山门开了 1700 多年。
> 一棵银杏，看过无数个秋天。
> 山还是那座山，寺还是那座寺。

### 画面落地

- **6 层**：天空 / 远山 / 寺院屋顶 / 大雄宝殿 / 山门 / 石阶与前景树枝。
- **光**：0–25s 晨光暖黄；25–40s 转暮色；40s 后回到暖光定格。
- **穿层**：12–22s 镜头穿过山门，进入第二层，这是全片的“签名瞬间”。
- **小人**：22–32s 从石阶下方走到中间，只占画面 1/20，不要抢戏。
- **朱印**：40s 落下，占画面 6%，方形，朱红 `#B4462F`，不要太大。
- **字体**：标题思源宋体，竖排“潭柘寺”；落款霞鹜文楷。

### 声音

- 0–5s：火柴 + 灯丝嗡鸣。
- 5–12s：纸张轻响，不要音乐。
- 12–32s：低频铺底 + 脚步 + 鸟鸣。
- 32–45s：单件大提琴进入，结尾收在一声钟。

### 风格提示词

> 用立体纸雕灯箱风格做一支 45 秒的潭柘寺短片。6 层纸雕：天空、远山、寺院屋顶、大雄宝殿、山门、石阶与前景树枝。暖色背光从后方打透，纸边有纤维和轻微卷曲。镜头从山门剪影缓慢推近，穿过山门进入第二层，最后拉远露出整个盒子。光从晨光转暮色。颜色只用纸白、牛皮、暖灯、松绿、朱砂、墨。不要 3D 塑料感，不要霓虹，不要快切。

## 3. 水墨版（30s，无旁白）

### 分镜

| 时间 | 画面 | 字幕 | 声音 |
|---|---|---|---|
| 0–5s | 空白宣纸，一滴墨落下 | 无 | 水滴 |
| 5–12s | 墨晕开成远山 | 无 | 古琴 |
| 12–20s | 干笔勾出屋檐，雾漫过 | 深山藏古寺 | 笔刷、风 |
| 20–26s | 一个小人沿石阶往上走 | 无 | 脚步、钟声 |
| 26–30s | 拉远，整幅山水，右侧竖排题字，左下朱印 | 潭柘寺 | 钟声余韵 |

### 画面落地

- 留白 ≥45%，主体在下方 1/3。
- 墨色只用焦、重、淡三层；赭石只用在屋顶。
- 全片只有一处朱红：左下角印章。
- 竖排标题在右，字距 +4%，不要居中大标题。
- 这是“情绪片”，不要塞历史年表。

### 风格提示词

> 用水墨风格做一支 30 秒的潭柘寺氛围片。米白宣纸，留白 45%。开头一滴墨落下，晕成远山；干笔勾出古寺屋檐；雾漫过来，一个小人沿石阶往上走；最后拉远，看到整幅山水。右侧竖排题字“深山藏古寺”，左下角一枚朱印。镜头像看长卷一样缓慢横移。不要快切，不要 3D，不要鲜艳的国潮渐变，不要讲历史数据。

## 4. 俯视立体版（45s）

### 分镜

| 时间 | 画面 | 字幕 | 旁白 | 声音 |
|---|---|---|---|---|
| 0–5s | 空底座，等距网格出现 | 潭柘寺 | 无 | 点击 |
| 5–15s | 山体、山门、大雄宝殿长出 | 北京城西 | 北京城西，太行余脉里的一座古寺。 | 建造声 |
| 15–25s | 帝王树、流杯亭、后山弹出，小人移动 | 五处看点 | 山门、大殿、帝王树、流杯亭、后山。 | 脚步 |
| 25–35s | 推近大雄宝殿，标签亮 | 大雄宝殿 | 中轴线上的最后一进。 | 高亮 |
| 35–42s | 拉远，完整模型 | 深山藏古寺 | 山还是那座山。 | 音乐起 |
| 42–45s | 定格，logo | 潭柘寺 | 无 | 轻响 |

### 画面落地

- 2:1 等距网格，45° 俯视。
- 标签最多 5 个：山门 / 大雄宝殿 / 帝王树 / 流杯亭 / 后山。
- 阴影统一从左上打来；人、车、楼比例要合理。
- 边缘加 2–3px 移轴模糊，中心清晰。
- 底座要完整，像放在桌上的一块模型盘。

### 风格提示词

> 用俯视等距微缩模型风格做一支 45 秒的潭柘寺导览片。2:1 等距网格，哑光黏土 / 纸板质感，软阴影从左上打来。底座上依次长出山体、山门、大雄宝殿、帝王树、流杯亭、后山，小人和小车在动。镜头从 45° 俯视缓慢环绕，推近大雄宝殿，五个标签依次亮起，最后拉远看到完整模型。不要写实 3D，不要塑料反光，不要超过 5 个标签。

---

## 5. 三种拍法怎么选

| 目的 | 选 | 原因 |
|---|---|---|
| 公众号首图 / 宣传片 | 立体纸雕 | 有温度、有空间、适合封面 |
| 文化副刊 / 深夜推送 | 水墨 | 情绪强，信息少，适合“留白” |
| 导览 / 亲子 / 地图 | 俯视立体 | 信息清楚，点位明确 |

## 6. 不要做什么

- 不要把“先有潭柘寺，后有北京城”写成史学结论。
- 不要在同一支片子里混用三种风格。
- 不要为了“震撼”加 3D 飞行镜头；这三种风格都怕“过火”。
- 不要用没有授权的老照片、佛造像图片。
- 不要把 45 秒塞进 10 个信息点；一支片子只讲一件事。
