## 地形 DEM（2026-10-20）

- 数据：Mapzen Terrarium / SRTM + GMTED，`elevation-tiles-prod`，z=9 共 20 块瓦片。
- 许可：CC BY 4.0（Mapzen Terrain Tiles）。
- 范围：`115.31–117.60E, 39.30–41.20N`，重采样为 240×200 网格。
- 用法：Three.js 地形网格 260×220，垂直夸张约 10×；城市/山脉/河流标签按经纬度投影。
- 这不是测绘级 DEM；垂直夸张会放大山形，片中标“DEM: SRTM / Mapzen”。
- 源瓦片：`https://s3.amazonaws.com/elevation-tiles-prod/terrarium/{z}/{x}/{y}.png`

## 3D 模型（2026-10-20）

- 数据：**BBBike Beijing OSM extract**，2026-10-17 更新，22.5MB。
  - 下载：https://download.bbbike.org/osm/bbbike/Beijing/Beijing.osm.pbf
  - 许可：**ODbL**，© OpenStreetMap contributors。
- 范围：老城 / 中轴，bbox `116.365–116.435, 39.868–39.942`。
- 建筑：**11,308 栋**真实 footprint；场景单位 1 = 10m，范围约 6.2km × 7.8km。
- 高度：OSM `height` / `building:levels` 优先；缺失按 **9m 示意**。不是每栋都有真实高度。
- 相机：南侧全景 → 中轴 → 故宫 → 景山 → 鼓楼 → 北侧拉远；30s，连续运动。
- 标签：永定门 / 天安门 / 故宫 / 景山 / 鼓楼，锚在 3D 点。
- 片中标：`1:2000 · OSM footprint · 非测绘`。

## 模型口径

- **真实**：建筑 footprint、面积、人口、中轴长度/遗产数量、中国尊高度、地形描述。
- **部分示意**：建筑高度（缺失按 9m）、环路几何、标签位置、太阳阴影。
- **非测绘**：不能用于测量、报批或导航。
- 每个数据层都有 source line；没有来源的数字不上屏。

## 不要写

- 不要写“北京有 X 万栋建筑”“建成区 X km²”，除非有官方来源。
- 不要把示意体块说成“真实建筑高度”。
- 不要把 1949 年人口写成“两百万”；官方口径是 420.1 万。
- 不要把中轴线说成“8 公里”；官方口径是 7.8 公里。
