# 一笔画 · One Line

> 一句话：一根线，画完一个故事。
> slug：`one-line`
> 适合：人性 / 情感 / 成长 / 品牌故事 / 诗歌 / 心理
> 不适合：数据 / 流程 / 产品参数 / 多人对话

## 1. 格式

- 画幅：16:9（默认）/ 9:16
- 时长：30–60s
- 帧率：30fps
- 字幕：底部，一句一行
- 旁白：贴近、克制，3–3.5 字/秒

## 2. 视觉契约

### 色板（只用这 4 个）

| 用途 | 色值 | 说明 |
|---|---|---|
| 纸白 | `#F6F1E7` | 背景 |
| 墨 | `#1B1B1B` | 主线 |
| 灰 | `#8A8175` | 辅助线、阴影 |
| 朱红 | `#C8553D` | 印章、一个点 |

### 字体

- 宋体 / 楷体，小字号，靠边
- 标题可以手写，但不要抢线
- 全片文字 ≤5 句

### 材质

- 纸张纤维，透明度 5%
- 墨线轻微洇开，边缘不完美
- 线宽 3–5px（1080p），有呼吸感
- 不要填充，不要渐变

### 版式

- 线是唯一主角，占画面 60% 以上
- 大量留白（≥35%）
- 文字放左下或右下，不要压线
- 结尾留一个红点 / 朱印

## 3. 镜头契约

- 机位：正面俯拍纸张
- 运动：镜头跟随线头，缓慢平移 / 推近
- 一镜到底：全片不剪切
- 线速：200–400px/s，情绪重时放慢
- 转场：线不断，直接变成下一个物体

## 4. 声音契约

- 笔尖划纸（持续、轻）
- 单音钢琴（每 4–6s 一个音）
- 呼吸 / 房间底噪
- 不要鼓点、不要大编制

## 5. 分镜模板（45s）

| 时间 | 画面 | 字幕 / 旁白 | 声音 |
|---|---|---|---|
| 0–5s | 一个点，线开始 | 一句提问 | 笔尖 |
| 5–15s | 线变成侧脸 | 一句观察 | 钢琴单音 |
| 15–25s | 线变成道路 / 房子 | 一句转折 | 笔尖 |
| 25–35s | 线变成鸟 / 手 | 一句答案 | 钢琴 |
| 35–42s | 线回到起点，成圆 | 一句总结 | 留白 |
| 42–45s | 红点 / 朱印，定格 | 落款 | 轻响 |

## 6. 风格提示词（可直接复制）

> 用一笔画风格做一支 45 秒短片。整片只有一根不断的黑线，在米白纸上生长，线宽 3–5px，边缘有轻微洇开。线依次变成侧脸、道路、房子、鸟，最后回到起点形成一个圆。镜头跟着线头缓慢移动，一镜到底，不剪切。全片只用一个墨色，结尾加一个朱红小点。不要提笔，不要填色，不要多色，不要快切。

## 7. 禁止项

- 提笔 / 断线
- 填充色、渐变、阴影
- 多色（除一个朱红点）
- 快切、抖动、故障风
- 复杂背景、真实照片
- 超过 5 句文字

## 8. 验收清单

- [ ] 线从头到尾没有断点
- [ ] 线宽一致，速度有变化但不跳
- [ ] 结尾回到起点或形成闭环
- [ ] 文字不压线，留白 ≥35%
- [ ] 全片只有 1 个强调色
- [ ] 旁白与线的形状同步
