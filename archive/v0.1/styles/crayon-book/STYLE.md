# 蜡笔绘本 · Crayon Book

> 一句话：像小时候那样，用力涂。
> slug：`crayon-book`
> 适合：儿童故事 / 睡前 / 亲子 / 儿童科普 / 家庭品牌 / 怀旧
> 不适合：B2B / 数据 / 严肃新闻 / 复杂产品

## 1. 格式

- 画幅：16:9（默认）/ 9:16
- 时长：30–60s
- 帧率：30fps
- 字幕：底部，大字，≤10 字/行
- 旁白：温柔、慢，3–3.5 字/秒；可用童声

## 2. 视觉契约

### 色板（只用这 6 个）

| 用途 | 色值 | 说明 |
|---|---|---|
| 纸白 | `#FBF6EA` | 纸张 |
| 蜡笔红 | `#D94F3D` | 主角、重点 |
| 蜡笔蓝 | `#3B6EA5` | 天空、水 |
| 蜡笔黄 | `#F2C14E` | 太阳、光 |
| 蜡笔绿 | `#5B8C5A` | 树、草地 |
| 蜡笔棕 | `#8B5E3C` | 房子、土地 |

### 字体

- 手写童体，字号大，基线略歪
- 标题可以像孩子写的，不要用黑体
- 每行 ≤10 字，最多两行

### 材质

- 纸张纹理明显（放大能看到纤维）
- 蜡笔颗粒，颜色涂出线外
- 线条歪歪扭扭，3–6px
- 叠色有蜡痕，不要平滑渐变
- 页面边缘有轻微阴影 / 卷角

### 版式

- 绘本单页，一页一个画面
- 文字在底部或左上，不要压主体
- 页码 / 小图案点缀
- 不要把画面塞满，留 15% 空白

## 3. 镜头契约

- 机位：正面看纸，轻微俯拍
- 运动：0–2% 推近，或不动
- 转场：翻页（纸张弯曲 + 阴影）
- 动作：角色上下轻晃，2s 一次；不要丝滑
- 节奏：每拍 6–10s，像翻书

## 4. 声音契约

- 蜡笔涂色沙沙
- 翻页声
- 八音盒 / 木琴 / 轻钢琴
- 孩子笑声（少量）
- 不要电子鼓、不要紧张弦乐

## 5. 分镜模板（50s）

| 时间 | 画面 | 字幕 / 旁白 | 声音 |
|---|---|---|---|
| 0–5s | 合上的绘本，标题 | 标题 | 八音盒 |
| 5–15s | 翻页，角色被画出来 | 第一句 | 蜡笔、翻页 |
| 15–25s | 角色走进场景 | 第二句 | 涂色 |
| 25–35s | 问题出现（乱涂） | 第三句 | 涂色加重 |
| 35–45s | 解决，暖色 | 第四句 | 音乐亮 |
| 45–50s | 翻页，“完” + 小印章 | 结尾 | 翻页 |

## 6. 风格提示词（可直接复制）

> 用蜡笔儿童绘本风格做一支 50 秒短片。米黄纸张，明显的纸纹和蜡笔颗粒，线条歪歪扭扭，颜色会涂出线外。角色是简单的小人 / 小动物，动作一颠一颠的，不要丝滑。转场用翻页。全片用蜡笔红、蓝、黄、绿、棕，像孩子画的。旁白温柔，像睡前故事。不要矢量感，不要渐变，不要 3D。

## 7. 禁止项

- 光滑矢量、渐变、3D
- 成人写实比例
- 暗色 / 恐怖 / 讽刺
- 快速剪辑、故障风
- 复杂图表、长句
- 超过 6 种蜡笔色

## 8. 验收清单

- [ ] 纸纹和蜡痕可见（放大看）
- [ ] 线条有抖动，不是完美曲线
- [ ] 颜色有涂出线外的部分
- [ ] 文字大、短、易读
- [ ] 翻页转场有纸张弯曲 / 阴影
- [ ] 整体温度偏暖
