# 俯视立体 · Isometric Diorama

> 一句话：把一座城，放成一个可以转的模型。
> slug：`isometric-diorama`
> 适合：景区导览 / 城市 / 园区 / 流程 / 产品生态 / 建筑 / 数据实物化
> 不适合：情绪特写 / 人物对话 / 密集文字

## 1. 格式

- 画幅：16:9（默认）/ 9:16
- 时长：30–60s
- 帧率：30fps
- 字幕：底部或侧边，配引线
- 旁白：清楚、稳，4 字/秒

## 2. 视觉契约

### 色板（只用这 6 个）

| 用途 | 色值 | 说明 |
|---|---|---|
| 底座 | `#E8E2D6` | 模型底板 |
| 草绿 | `#8FAF7E` | 绿地、树 |
| 砖红 | `#B65C4A` | 屋顶、重点建筑 |
| 水蓝 | `#6FA3B8` | 水、玻璃 |
| 路米 | `#D9CBB5` | 道路、广场 |
| 强调黄 | `#F2C14E` | 高亮、标签 |

### 字体

- 无衬线（思源黑体），字号小，配细引线
- 标签最多 5 个同时出现
- 数字用等宽，单位写清楚

### 材质

- 哑光黏土 / 纸板质感，不要塑料反光
- 软阴影，方向统一（左上光）
- 轻微移轴模糊（边缘 2–3px）
- 小人和车是简化几何，不要写实

### 版式

- 2:1 等距网格（30°）
- 3–5 个区域，一个主建筑
- 标签放空白处，引线不交叉
- 底座边缘可见，像模型盘

## 3. 镜头契约

- 机位：45° 俯视等距（也可 90° 纯俯视）
- 运动：缓慢环绕 ±10°，推近一个区域，再拉远
- 建造：区域逐个“长出来”，0.6s/个
- 高亮：一圈黄色脉冲，2s
- 转场：镜头平移 / 区域升降

## 4. 声音契约

- 轻点击（建筑出现）
- 小脚步声 / 车流（很轻）
- 环境底噪
- 音乐：轻电子 / 马林巴，100–110 BPM

## 5. 分镜模板（45s）

| 时间 | 画面 | 字幕 / 旁白 | 声音 |
|---|---|---|---|
| 0–5s | 空底座，网格出现 | 标题 | 点击 |
| 5–15s | 地形和主建筑长出 | 一句定位 | 建造声 |
| 15–25s | 次区域弹出，小人移动 | 一句细节 | 脚步 |
| 25–35s | 推近主区域，标签亮 | 关键信息 | 高亮 |
| 35–42s | 拉远，完整模型 | 结尾句 | 音乐起 |
| 42–45s | 定格，logo | 落款 | 轻响 |

## 6. 风格提示词（可直接复制）

> 用俯视等距微缩模型风格做一支 45 秒短片。2:1 等距网格，哑光黏土 / 纸板质感，软阴影从左上打来。画面是一个 3–5 个区域的微缩景区 / 园区，主建筑在中间偏下，小人和小车在动。镜头从 45° 俯视缓慢环绕，推近主区域，标签依次亮起，最后拉远看到完整模型。不要写实 3D，不要塑料反光，不要暗色，不要超过 5 个标签。

## 7. 禁止项

- 写实 3D / 照片贴图
- 塑料高光、金属反射
- 暗色调、赛博朋克
- 比例混乱（人比楼大）
- 超过 5 个标签同时出现
- 快速环绕 / 眩晕运镜

## 8. 验收清单

- [ ] 等距角度一致（30°），没有透视打架
- [ ] 阴影方向统一
- [ ] 人 / 车 / 楼比例合理
- [ ] 标签不重叠、引线不交叉
- [ ] 边缘有移轴模糊，中心清晰
- [ ] 底座完整，像模型盘
