# 验收清单

## 文字

- [ ] 无错字、无多字、无缺字
- [ ] 没有文字溢出安全区
- [ ] 没有缺字（字体已嵌入或兜底）
- [ ] 竖排标点、断行正确
- [ ] 数字、单位、人名、地名已核对

## 时间

- [ ] 总时长与脚本一致（±0.2s）
- [ ] 没有 >2s 的无意义空镜
- [ ] 每拍开始/结束与旁白对齐（±0.3s）
- [ ] 结尾定格 ≥1s

## 风格

- [ ] 色板只用 STYLE.md 里的颜色
- [ ] 运动只用 STYLE.md 里的词汇
- [ ] 没有触犯“禁止项”
- [ ] 有一个明确的“签名瞬间”
- [ ] 与同项目其他片子放在一起，像一家人

## 声音

- [ ] 人声清晰，不被音乐盖住
- [ ] 没有爆音 / 削波
- [ ] SFX 与画面同步
- [ ] 整体响度约 -14 LUFS

## 事实与版权

- [ ] 所有数字、引语有来源，并写进 `sources.md`
- [ ] 没有把民间说法写成“史料记载”
- [ ] 字体、音乐、图片均有授权
- [ ] 没有未经许可的商标 / 人物肖像

## 文件

- [ ] 1080p，H.264，AAC
- [ ] 文件 <50MB
- [ ] 文件名不含空格
- [ ] 附带 `brief.md`、`script.md`、`scene.html`、`preview.jpg`
