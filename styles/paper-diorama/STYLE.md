# 立体纸雕 · Paper Diorama

> 一句话：把风景装进一个会发光的纸盒子里。
> slug：`paper-diorama`
> 适合：景区 / 古建 / 地标 / 节日 / 文化品牌 / 片头
> 不适合：数据 / 参数 / 快节奏解说 / 抽象概念

## 1. 格式

- 画幅：16:9（默认）/ 9:16
- 时长：30–60s
- 帧率：30fps
- 字幕：底部安全区，最多两行，每行 ≤12 字
- 旁白：温和、慢，3.5–4 字/秒

### 资料（开拍前必须找到）

- **点位与年代**：山门、主殿、古树、后山，各自的名称与大致年代
- **一句地方说法**：能当结尾的民间说法（必须标注“民间说法”，不能写成史料）
- **一个能画出来的空间关系**：谁在前、谁在后、镜头从哪穿过去
- **不要编“某年某月”**：查不到的细节，用“很久以前 / 一千多年”这类表述

## 2. 视觉契约

### 色板（只用这 6 个）

| 用途 | 色值 | 说明 |
|---|---|---|
| 纸白 | `#F3EBDD` | 最前层、天空、留白 |
| 牛皮 | `#C9A77C` | 中景纸层、边框 |
| 暖灯 | `#FFB86B` | 背光、灯箱、光晕 |
| 松绿 | `#4E6E5D` | 树木、山体 |
| 朱砂 | `#B4462F` | 印章、重点、屋顶 |
| 墨 | `#1E1A17` | 剪影、文字、最深一层 |

### 字体

- 标题：思源宋体 SemiBold，字距 +2%
- 正文：思源黑体 Regular
- 落款：霞鹜文楷，竖排
- 英文：用同一宋体，不要换字体

### 材质

- 纸纤维：细噪点 + 轻微纹理，透明度 4–8%
- 切边：1px 亮边 + 1px 暗边，模拟纸的厚度
- 卷曲：边角 1–2° 微翘，不要每层都翘
- 阴影：柔和、方向一致，来自背光
- 灰尘：少量漂浮颗粒，速度 <5px/s

### 版式

- 5–7 层：前景剪影 / 中景主体 / 远景山形 / 天空
- 主体偏下 1/3，上方留光
- 标题放在最前层，或最后拉远的盒子上
- 不要满屏，盒子边缘要可见

## 3. 镜头契约

- 机位：正面略俯（5–10°），不要大角度
- 运动：缓慢推近（0→8%），穿过 1–2 层；最后拉远
- 焦点：在层与层之间切换，一次只清一层
- 转场：灯光变化 / 纸层滑入 / 拉远，不用叠化
- 节奏：每拍 6–10s，全片 ≤3 次运镜

## 4. 声音契约

- 底噪：安静房间，-38dB
- SFX：纸张轻响、灯丝嗡鸣、远处钟声
- 音乐：单件乐器（钢琴 / 大提琴），60–70 BPM
- 人声：贴近、温暖，不要播音腔

## 5. 分镜模板（45s）

| 时间 | 画面 | 字幕 / 旁白 | 声音 |
|---|---|---|---|
| 0–5s | 黑场，火柴划亮，灯箱亮起 | 无 | 划火柴、灯丝嗡鸣 |
| 5–12s | 最前层剪影（山门 / 树），缓慢推近 | 标题 | 纸响 |
| 12–22s | 纸层分开，露出寺院的深度 | 一句定位 | 低音铺底 |
| 22–32s | 光从晨转暮，一个小人走过 | 一句细节 | 脚步声、鸟鸣 |
| 32–40s | 拉远，整个盒子可见 | 结尾句 | 音乐起 |
| 40–45s | 朱印落下，定格 | 印章 / 落款 | 印章闷响 |

## 6. 风格提示词（可直接复制）

> 用立体纸雕灯箱的风格做一支 45 秒短片。画面是一个 5–7 层的纸雕盒子，暖色背光从后方打透，纸的边缘有纤维和轻微卷曲。镜头从最前层的剪影缓慢推进，逐层穿过，最后拉远露出整个盒子。颜色只用纸白、牛皮、暖灯、松绿、朱砂、墨。不要 3D 塑料感，不要霓虹，不要快切，不要满屏。

## 7. 禁止项

- 扁平矢量插画
- 霓虹色、赛博色
- 塑料 / 金属 3D 质感
- 完美对称、完美边缘
- 快切、甩镜、故障风
- 超过 7 层或超过 6 色

## 8. 验收清单

- [ ] 层数与顺序正确，阴影方向一致
- [ ] 纸边有亮 / 暗边，不是纯色块
- [ ] 光源始终来自后方，没有前后矛盾
- [ ] 标题在安全区内，竖排没有断字
- [ ] 全片至少有一个“穿层”镜头
- [ ] 结尾定格 ≥1s
