# 白模投影 · Projection on White Model

> 一句话：一座纯白的城市模型摆在暗房里，投影仪把数据一层层打在它身上——模型不动，只有光在动。
> slug：`white-model`
> 适合：城市 / 区域 / 园区 / 规划 / 地理 / 人口 / 交通 / 时间变化
> 不适合：情绪故事 / 人物特写 / 儿童内容 / 没有可靠数据的题材

这个风格的“真”来自两件事：**模型是真实几何**（开放数据里的建筑轮廓与高度），**数据是光**（不是贴图、不是花纹）。没有数据就不要用这个风格——它靠数字立身。

## 1. 格式

- 画幅：16:9（默认）
- 时长：45–120s；60–120s 才能讲完“地理 → 历史 → 今天”
- 帧率：24fps
- 字幕：烧录或外挂；左下读数列，单行 ≤16 字
- 旁白：平稳、报数清楚；数字要念全，不要含糊

### 资料（开拍前必须找到）

- **真实轮廓数据**：OpenStreetMap / 城市开放数据 / 用户自有数据；注明许可（ODbL / CC BY / CC0）
- **高度或层数**：OSM `height` / `building:levels` 优先；缺失时可给“示意高度”，但必须在片中标明
- **地形**：DEM（SRTM / GMTED / 本地测绘），说明垂直夸张倍数
- **3–6 个可核对数字**：面积、人口、长度、高度、年代；每个都要有来源链接
- **一份 `FACTS.md`**：说法 / 来源 / 原文 / 计算方式；和成片一起交付

宁可少一层数据，不要编一层。没有来源的数字不上屏。

## 2. 视觉契约

### 色板（只用这 6 个）

| 用途 | 色值 | 说明 |
|---|---|---|
| 白模 | `#F3F3F1` | 建筑、地形、底座，哑光 |
| 暗房 | `#0C0D10` | 房间、背景、未被打亮的部分 |
| 琥珀 | `#E8A33D` | “旧的 / 例外的那一类” |
| 投影蓝 | `#5B8DEF` | 连续数据：时间、高度、密度 |
| 水面 | `#C9CDD4` | 水体、缎面内嵌、基座高光 |
| 基座 | `#1A1C22` | 底座、暗面、读数字底条 |

**颜色规则**：模型永远是白的，颜色只能“投”上去；一层数据只用一个色系；同一个颜色回来，必须还是同一个意思。

### 字体

- 数字：无衬线细体（Inter Tight 200 / 思源黑体 Light），120–140px
- 标签：思源黑体 300/500，20–36px
- 仪表：等宽（IBM Plex Mono），18–22px，用于年份、坐标、单位

### 材质

- 模型：哑光白（roughness ≈ 0.9），边缘干净，不要塑料反光
- 光：一盏柔和的室内主光 + 环境光遮蔽；投影是**加在受光面上的项**，不是贴图
- 水面：比白模更暗的缎面内嵌，能接住一点投影
- 底座：深色缎面，投影可以溢到台面上一点，但不出画面
- 颗粒：轻微胶片颗粒；不要 CRT 扫描线

### 版式

- 读数列固定在左 1/3：序号 + 层名 + 一个数字 + 一个标签 + 一行出处
- 每层只允许一个数字；第二个数字就是下一层
- 标注：从屋顶或地面点拉一根细线到暗色标签条
- 图例条只在需要时出现，出现后不要立刻消失

## 3. 镜头契约

- 机位：从南侧或东南侧起，45° 左右俯视；不要钻到模型内部
- 运动：连续推近 / 沿中轴平移 / 缓慢环绕；一次只做一件事
- 焦点：近景浅景深，广角深景深；不要全程虚化
- 转场：灯灭 → 灯亮；投影切换；不要叠化、不要白闪
- 节奏：每层 8–15s；一层讲完再开下一层

## 4. 声音契约

- 旁白：报数清楚，句间留 0.4s
- 音乐：低频铺底 + 单件乐器；层切换处给一个轻击
- 拟音：投影仪风扇、灯丝、轻微的模型移动声（其实模型不动，是错觉）
- 太阳段：环境声进来，音乐退
- 全片 −14 LUFS，真峰值 ≤ −1.2 dB

## 5. 分镜模板（90s）

| 时间 | 画面 | 字幕 / 旁白 | 声音 |
|---|---|---|---|
| 0–8s | 暗房，灯亮，白色模型；投影仪启动 | 标题 / 比例尺 | 投影仪、灯丝 |
| 8–22s | 地形层：山形与平原被绿光洗过 | 面积 / 三面环山 | 低频、风 |
| 22–40s | 中轴与老城层：地点依次亮起，波光向外扩散 | 长度 / 年代 / 世界遗产 | 轻击、低频 |
| 40–58s | 天际线层：楼群长高，最高的那栋突出 | 高度 / 年份 | 计数、脉冲 |
| 58–72s | 人口层：计数器从旧数字走到新数字 | 两个人口数 | 计数声 |
| 72–84s | 太阳层：真实方位与长影子扫过 | 时间 / 日期 | 环境声 |
| 84–90s | 灯亮，模型回到白色，落款 | 片名 | 收尾 |

## 6. 风格提示词（可直接复制）

> 用白模投影的风格做一支 90 秒短片。暗房里放着一座纯白的城市模型，是真实建筑轮廓和高度（开放数据），投影仪把数据一层层打在它身上：地形、中轴、天际线、人口、太阳。模型永远不动，只有光在动；颜色只出现在朝向投影的面上，墙背面会暗下去。镜头从南侧缓慢推近，沿中轴平移，最后拉远。左下角是读数列，每层只给一个数字和一行出处。不要全息线框，不要发光网格，不要给模型上色，不要编造地形。

## 7. 禁止项

- 全息线框 / 科幻 HUD / 发光网格
- 给模型本体上色（颜色只能是光）
- 编造地形、编造建筑、用生成图代替真实几何
- 一屏出现两个以上数据层
- 数字没有来源，或把“示意”说成“实测”
- 无人机式穿越镜头、快速环绕

## 8. 验收清单

- [ ] 每一层数据都有来源，写进 `FACTS.md` 和 `sources.md`
- [ ] 高度缺失处已标注“示意”，或改用有数据的层
- [ ] 颜色只出现在受光面，背光面自然变暗
- [ ] 一个镜头里只有一个数据层、一个数字
- [ ] 地图/影像/地形许可已注明（ODbL / CC BY / CC0）
- [ ] 太阳方位与日期一致（若使用太阳层）
- [ ] 片尾或说明区有数据来源与比例尺
