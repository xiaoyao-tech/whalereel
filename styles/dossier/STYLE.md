# 档案卷宗 · Redacted Dossier

> 一句话：全片是一份卷宗。纸是唯一的舞台，摄像机是翻卷宗的手。
> slug：`dossier`
> 适合：历史人物 / 案件复盘 / 制度解释 / 调查报告 / 传记 / 企业史 / 家族史
> 不适合：儿童 / 快节奏产品广告 / 纯情绪片 / 需要真实影像的纪录片

这个风格不是先挑好看的，是从稿子里长出来的：当你的稿子是一串档案式的事实（年份、地点、谁死了、谁没给），核心物件又全是纸（户籍、批文、名册、判决），片子就不该“演”，该“查”。

## 1. 格式

- 画幅：16:9（默认）/ 9:16 需重排版面，不推荐
- 时长：30–60s；长内容拆集，每集 ≤50s
- 帧率：24fps（比 30fps 更像档案翻拍）
- 字幕：烧录或外挂；底部深色条，单行 ≤18 字
- 旁白：3.5–4 字/秒，句尾不扬；像在念一份记录，不像在演讲

### 资料（开拍前必须找到）

- **3–6 个可核对的事实**：年份、地点、人物、数字，每个都要有出处
- **一条时间线**：至少 3 个节点，能排成“之前 / 那一年 / 之后”
- **1–2 个纸上物件**：户籍 / 花名册 / 批文 / 证件 / 判决 / 报表——它们是画面主体，选你手上真有出处的
- **一句判断句**：全片只允许一句，放在最后

没有来源的数字，不上屏；宁可少讲一个，不要编。

## 2. 视觉契约

### 色板（只用这 6 个）

| 用途 | 色值 | 说明 |
|---|---|---|
| 纸 | `#EDE3CB` | 全部画面 |
| 纸亮 | `#F7EFDD` | 被灯照到的那一块 |
| 墨 | `#1B1611` | 字、线、涂黑条 |
| 印泥 | `#A82E1C` | 只给“判决”：印、不准、无载 |
| 桌 | `#15110D` | 纸外的暗 |
| 标签灰 | `#8A7A63` | 页眉、编号、注释 |

**朱红规则**：只在一个人被制度定性的时候出现。即位、卒、不准、僧、丐、名字落印。它从不做装饰，从不出现在标题上。

### 字体

- 标题：宋体 700，字距 16，150px
- 正文：打字机（Courier New）+ 宋体混排，30–34px
- 标签：等宽 26px，透明度 55%
- 编号：`<项目代号>—001` 这类格式（如 `HW—001`、`AR—007`），永远在左上角

### 材质

- 纸纤维：细噪点 + 轻微纹理，透明度 4–8%
- 压痕：2–3 条极淡的横向折痕，不要布满
- 边缘：四边有一圈暗角，像灯照不到的地方
- 倾斜：整张纸 0.43°，不要摆正
- 桌上：纸外是近黑的桌面，可见一点木纹

### 版式

- 一张 1520×920 的纸，四边留 90px
- 页眉：左“档号”，右“年份/地点”，下面一条 1.4px 细线
- 表格用虚线；虚线是“待填”，实线是“已定”
- 一页最多 3 个信息块；多一个就分页
- 涂黑条从左侧滑入，宽 0→满，0.26s，末尾略过冲

## 3. 镜头契约

- 机位：正视纸面，略俯 2°；不要斜切、不要透视夸张
- 运动：只有三种——缓慢推近（1.00→1.05）、向下摇（从表格摇到批复）、印章落下的抖
- 焦点：纸面永远清晰；不要虚化文字
- 转场：硬切，切点配一声纸响；没有叠化、没有翻页动画
- 节奏：每页 5–8s；静止就是静止，靠“打字的出现”制造动

## 4. 声音契约

- 旁白：平稳、克制，句间留 0.3–0.5s
- 拟音：打字机“嗒”（800–5200Hz 带通 + 210Hz 木体）、纸的翻动、印章闷响（64Hz + 瞬态）
- 底：40–220Hz 房间底噪 + 一条极低持续音，随页变化
- 落印：一声低磬（196Hz 基频 + 三个分音），然后留白
- 没有配乐旋律；全片 −14 LUFS，真峰值 ≤ −1.0 dB

## 5. 分镜模板（45s）

| 时间 | 画面 | 字幕 / 旁白 | 声音 |
|---|---|---|---|
| 0–6s | 卷宗封面，打字机打出档号、时间、地点、事由 | 标题 | 打字机、纸响 |
| 6–14s | 户籍/名册页，三行被涂黑，标“无载” | 一句事实 | 涂黑滑入、低音 |
| 14–22s | 镜头下移，露出批复栏，一枚“不准” | 一句转折 | 印章、留白 |
| 22–30s | 物件页：证件 / 批文 / 报表 / 判决，两枚章 | 一句细节 | 纸响、章 |
| 30–38s | 数字页：一个数字占半屏，配一条虚线 | 一个数字 + 出处 | 计数、低音 |
| 38–43s | 空白页，逐字打出结论句 | 判断句 | 打字机、磬 |
| 43–45s | 落印，定格 | 落款 | 印章闷响 |

## 6. 风格提示词（可直接复制）

> 用档案卷宗的风格做一支 45 秒短片。全片是一份米色卷宗：纸微微倾斜 0.43°，有纤维、压痕和边缘的暗。画面里没有人物插图，信息全由字号、位置、留白和印章承担。打字机逐字打出文字，涂黑条从左侧滑入盖住名字。全片只有一种彩色——印泥的朱红，只出现在“被定性”的六个时刻。镜头只会推近、下摇、停住，切页是硬切配纸响。不要年代剧再现，不要做旧滤镜，不要翻页动画，不要红色装饰。

## 7. 禁止项

- 年代剧服装、置景、演员再现
- 做旧滤镜、烧焦羊皮、泛黄老照片拼贴
- 真实人物肖像、未授权档案扫描件
- 把朱红当装饰（全片红面积 >2%）
- 翻页动画、叠化、镜头甩动
- 一屏超过 3 个信息块，或字号小于 24px

## 8. 验收清单

- [ ] 每个数字、年份、引语都有出处，已写进 `sources.md`
- [ ] 涂黑条盖住的是“名字”，不是标签
- [ ] 朱红总面积 ≤2%，且只出现在“被定性”的时刻
- [ ] 印章有缺墨、错位、毛边，不是干净的矢量图
- [ ] 打字机每行有 1–2px 漂移，光标 2Hz 闪
- [ ] 全片至少一次“推近读出细节”，至少一次“留白 1s 以上”
- [ ] 结论句只出现一次，且是全片最后一句
