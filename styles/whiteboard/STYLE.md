# 白板讲解 · Whiteboard

> 一句话：一支马克笔，把一件事画明白。
> slug：`whiteboard`
> 适合：知识 / 原理 / 流程 / 课程 / 产品上手 / 科学解释
> 不适合：情绪片 / 景区宣传 / 儿童故事 / 高端品牌

## 1. 格式

- 画幅：16:9（默认）/ 9:16
- 时长：45–60s
- 帧率：30fps
- 字幕：底部，最多两行
- 旁白：清楚、偏快，4.5–5 字/秒

### 资料（开拍前必须找到）

- **一个能被画出来的结构**：三层以内，每层一个词
- **一条三步以内的路径**：从问题到答案，中间不放第四个框
- **一个常见误解**：开场先画错的那个版本
- **一个数字或反例**：让结论站得住；没有就只用逻辑，不要编数据

## 2. 视觉契约

### 色板（只用这 6 个）

| 用途 | 色值 | 说明 |
|---|---|---|
| 板面 | `#F7F7F2` | 白板，带一点灰 |
| 墨黑 | `#1F2328` | 主线条、文字 |
| 强调蓝 | `#2F6BFF` | 关键词、箭头 |
| 警示橙 | `#E4572E` | 错误、对比 |
| 便签黄 | `#FFE08A` | 补充信息 |
| 磁铁红 | `#C0392B` | 固定、重点 |

### 字体

- 手写马克笔体（霞鹜文楷 / 站酷快乐体，选一个）
- 标题比正文大 1.6×
- 不要用宋体 / 黑体，会像 PPT

### 材质

- 板面细纹，透明度 3%
- 马克笔边缘轻微洇开
- 擦除留灰痕，不要擦得干干净净
- 便签有轻微卷角，磁铁有高光

### 版式

- 从左到右、从上到下构建
- 每拍最多 3 个元素
- 中心留出“结论区”，最后写
- 安全区 5%，不要画到边

## 3. 镜头契约

- 机位：固定俯拍，不要手持
- 运动：0–3% 推近，或不动
- 绘制：线条 0.6–1.2s 画完，笔尖跟随
- 圈注：顺时针 1.5 圈，略超出起点
- 擦除：一次性横向擦过，0.4s
- 转场：擦除 / 翻页 / 便签贴入

## 4. 声音契约

- 马克笔沙沙（每画一笔）
- 笔帽咔哒（换色）
- 板擦摩擦（擦除）
- 轻点击（元素出现）
- 音乐：轻电子 / 木吉他，90–110 BPM，音量 -22dB

## 5. 分镜模板（60s）

| 时间 | 画面 | 字幕 / 旁白 | 声音 |
|---|---|---|---|
| 0–4s | 空板，写下标题 | 标题 | 马克笔 |
| 4–14s | 画核心对象 | 一句定义 | 马克笔 |
| 14–26s | 加标签、箭头 | 拆解 | 笔帽、点击 |
| 26–38s | 圈出关键，写“为什么” | 关键句 | 圈注 |
| 38–50s | 擦掉干扰项，写总结框 | 总结 | 板擦 |
| 50–60s | 下划线，定格 | 行动句 | 点击 |

## 6. 风格提示词（可直接复制）

> 用白板讲解风格做一支 60 秒短片。白板底色微灰，黑色马克笔手绘，蓝色做强调，橙色做对比。所有图形一笔一笔画出来，笔尖跟随线条；重点用圆圈和下划线，不要用高亮块。每拍最多三个元素，最后擦掉干扰项，留下一个总结框。不要 PPT 飞入，不要完美矢量图标，不要超过三种颜色。

## 7. 禁止项

- PPT 式飞入 / 淡入
- 完美矢量图标、渐变
- 超过 3 种马克笔颜色
- 大段文字（>12 字/行）
- 真实人手（容易恐怖谷）；用笔尖或极简手
- 背景音乐盖过人声

## 8. 验收清单

- [ ] 720p 下能看清最小字
- [ ] 每拍元素 ≤3，无重叠
- [ ] 线条速度一致，没有“瞬间出现”
- [ ] 擦除有灰痕，不是硬切
- [ ] 结论区只出现一次
- [ ] 旁白与绘制同步（±0.3s）
