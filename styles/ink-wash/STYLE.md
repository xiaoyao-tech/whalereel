# 水墨 · Ink Wash

> 一句话：留白处，才是山水。
> slug：`ink-wash`
> 适合：山水 / 古寺 / 诗词 / 武侠 / 茶香酒 / 文化品牌 / 历史人物 / 情绪片
> 不适合：数据 / 参数 / 流程 / 快节奏解说 / 儿童内容

## 1. 格式

- 画幅：16:9（默认）/ 9:16
- 时长：30–60s
- 帧率：30fps
- 字幕：竖排优先，右侧；横排时放底部
- 旁白：慢、低，2.5–3 字/秒；也可以无旁白

### 资料（开拍前必须找到）

- **一处景或一句诗**：全片只讲一个画面，不要年表
- **一个可留白的结尾**：题字或一枚印，不要总结陈词
- **不要历史数据**：出现“三步 / 参数 / 对比”，换白板讲解
- **不要国潮渐变素材**：所有笔触自己画

## 2. 视觉契约

### 色板（只用这 6 个）

| 用途 | 色值 | 说明 |
|---|---|---|
| 宣纸 | `#F4EFE4` | 背景 |
| 焦墨 | `#141414` | 最近的山、字 |
| 重墨 | `#2C3E50` | 中景 |
| 淡墨 | `#8A9BA8` | 远山、雾 |
| 赭石 | `#A67C52` | 屋顶、土坡 |
| 朱砂 | `#B03A2E` | 印章、唯一亮点 |

### 字体

- 标题：宋体 / 楷体，竖排，字距 +4%
- 正文：小楷 / 宋体，字号小
- 英文：不要出现，或极小
- 印章：篆刻感，方形，朱红

### 材质

- 宣纸纤维，透明度 6–10%
- 墨分五色：焦、重、浓、淡、清
- 湿边：墨迹边缘有 1–2px 深色水线
- 飞白：干笔有断丝
- 不要用纯黑大面积填充

### 版式

- 留白 ≥40%
- 主体在下方 1/3，上方是雾 / 天
- 竖排标题在右，印章在左下或右下
- 不要满、不要对称、不要居中大标题

## 3. 镜头契约

- 机位：平视或略俯，像看一卷画
- 运动：缓慢横移（长卷感），2–5% 推近
- 焦点：雾前 / 雾后切换，一次只清一层
- 转场：墨晕散开 / 雾飘过 / 留白
- 节奏：每拍 6–10s，允许 2s 空镜

## 4. 声音契约

- 毛笔擦纸
- 古琴 / 箫，单声部
- 水滴、风、远处钟声
- 不要鼓、不要合成器、不要大混响

## 5. 分镜模板（50s）

| 时间 | 画面 | 字幕 / 旁白 | 声音 |
|---|---|---|---|
| 0–6s | 空白宣纸，一滴墨 | 无 | 水滴 |
| 6–16s | 墨晕开成远山 | 一句诗 | 古琴 |
| 16–26s | 干笔勾出屋檐 | 一句定位 | 笔刷 |
| 26–36s | 雾漫过，出现小人 | 一句细节 | 风 |
| 36–44s | 拉远，整幅山水 | 结尾句 | 钟声 |
| 44–50s | 落款、朱印 | 印章 | 轻响 |

## 6. 风格提示词（可直接复制）

> 用水墨风格做一支 50 秒短片。米白宣纸背景，墨分五色，留白至少 40%。开头一滴墨落下，慢慢晕成远山；干笔勾出古寺屋檐；雾漫过来，一个小人沿石阶往上走；最后拉远，看到整幅山水，右侧竖排题字，左下角一枚朱印。镜头像看长卷一样缓慢横移，不要快切，不要 3D，不要鲜艳的国潮渐变。

## 7. 禁止项

- 高饱和“国潮”配色、金光特效
- 3D、硬边矢量、塑料质感
- 满屏、密字、居中大标题
- 快切、甩镜、故障风
- 超过 3 种墨色 + 1 个朱红
- 把水墨当“滤镜”贴在实拍上

## 8. 验收清单

- [ ] 留白 ≥40%，画面不闷
- [ ] 墨色层次 ≥3 层（焦 / 重 / 淡）
- [ ] 湿边 / 飞白至少出现一次
- [ ] 竖排标题断字正确，印章不抢戏
- [ ] 全片只有一处朱红
- [ ] 至少 2s 的“空”镜头
