# 风格索引

六种风格，每种一份 `STYLE.md`、一支样片、一份验收清单。

| slug | 风格 | 一句话 | 最适合 | 开拍前要有 |
|---|---|---|---|---|
| [`dossier`](dossier/STYLE.md) | 档案卷宗 | 一张米色卷宗纸，涂黑条盖住名字，印章落下 | 历史人物、案件、制度、调查 | 3–6 条有出处的事实 |
| [`pen-wash`](pen-wash/STYLE.md) | 钢笔淡彩 | 先有线，后有颜色；颜色跟着一件事走 | 情绪、乡愁、城市漫游、歌曲意象 | 一个地点 + 一个颜色事件 |
| [`white-model`](white-model/STYLE.md) | 白模投影 | 纯白模型在暗房，投影把数据一层层刷上去 | 城市、区域、规划、地理、人口 | 真实轮廓 + 高度 + 地形 |
| [`paper-diorama`](paper-diorama/STYLE.md) | 立体纸雕 | 暖光穿过 5–7 层纸，镜头逐层推进 | 景区、古建、地标、节日 | 点位、年代、一句地方说法 |
| [`whiteboard`](whiteboard/STYLE.md) | 白板讲解 | 一支马克笔，边画边讲 | 知识、原理、流程、课程 | 一个能画出来的结构 |
| [`ink-wash`](ink-wash/STYLE.md) | 水墨 | 留白、墨韵、一枚朱印 | 山水、古寺、诗词、品牌片头 | 一处景或一句诗 |

## 怎么选

| 观众看完要做什么 | 选 |
|---|---|
| 去查、去相信 | 档案卷宗 |
| 被打动 | 钢笔淡彩 |
| 看清一个地方 / 一组数据 | 白模投影 |
| 想去这个地方 | 立体纸雕 |
| 看懂一件事 | 白板讲解 |
| 静下来 | 水墨 |

## 不要这样选

- 有数据但没来源 → 不要白模投影，换白板讲解。
- 有史料但核不出来 → 不要档案卷宗，换水墨。
- 想要旁白讲道理 → 不要钢笔淡彩，换白板讲解。
- 想讲三步流程 → 不要水墨，它负责氛围不负责解释。

## 一份 STYLE.md 里有什么

1. 格式（含“资料”清单）
2. 视觉契约（色板 ≤6 色、字体、材质、版式）
3. 镜头契约（机位、运动、焦点、转场、节奏）
4. 声音契约
5. 分镜模板
6. 风格提示词（可直接复制）
7. 禁止项
8. 验收清单
9. 参考

新增风格：复制 `_template/`，填完 9 节，加进 `index.json`，跑 `node scripts/validate-styles.mjs`。
