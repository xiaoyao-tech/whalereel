# 钢笔淡彩 · Pen & Wash

> 一句话：先有线，后有颜色；颜色不是涂上去的，是跟着一件事漫过去的。
> slug：`pen-wash`
> 适合：情绪 / 乡愁 / 城市漫游 / 人物侧写 / 歌曲意象 / 品牌抒情片
> 不适合：数据 / 参数 / 流程 / 快节奏解说 / 儿童科普

风格的核心不是“水彩滤镜”，是**两个介质的分工**：钢笔负责结构与记忆，淡彩负责情绪与此刻。线永远在，颜色会退。

## 1. 格式

- 画幅：16:9（默认）/ 9:16 可用，但要把正文收进中间 2/3
- 时长：30–60s；60s 是这种风格的舒适区
- 帧率：24fps；人物可降到 12fps 制造“手绘抖动”（boil）
- 字幕：少量手写体，≤3 处；不要整片字幕
- 旁白：默认**无旁白**；要让线自己说话。必须有时，只用短句

### 资料（开拍前必须找到）

- **一个具体地点**：有桥、有巷、有窗，能画出来的那种
- **一段可压缩的时间**：一夜 / 一季 / 十年，观众要能感到“过去了”
- **一个颜色事件**：什么东西经过，哪里才有颜色（灯笼、雨、车灯、一个人）
- 如果涉及真实作品（歌曲、小说、地方），**只借意象，不引原文**；版权写进 `sources.md`

## 2. 视觉契约

### 色板（只用这 6 个）

| 用途 | 色值 | 说明 |
|---|---|---|
| 纸 | `#F5EEDE` | 冷压水彩纸，全片底色 |
| 墨 | `#2E2622` | 钢笔线、字、暗部 |
| 淡青 | `#8EA6C4` | 水、夜、远山 |
| 赭 | `#C89274` | 墙、木、皮肤 |
| 朱 | `#D97757` | 唯一的“事件色”：灯笼、衣角、印章 |
| 灰绿 | `#6F8A55` | 树、苔、岸边植物 |

**颜色到达规则**：全片开头只能是线；颜色随某一件事进入画面，跟着它走；结尾让颜色退回去，只留一处朱。

### 字体

- 标题：手写体（霞鹜文楷 / 楷体），字距 +4%
- 正文：不排正文；只允许 3 处手写短语
- 落款：竖排，靠右下，字号小

### 材质

- 纸：冷压纹、mottling、可见纸齿；边缘略毛
- 线：单色、有抖动、有出头、有断笔；不要矢量般光滑
- 淡彩：半透明、错位 1–2px、有积色边、有颗粒
- 颜色不铺满：留白 ≥35%，纸上要有“没画完”的地方
- 人物：2D 剪影 + 12fps boil；看不到五官，只看到姿态

### 版式

- 一张纸就是画框；四边留白不等宽，下边距最宽
- 主体偏下 1/3；上方留天、留雾
- 文字永远小于画面里最小的建筑构件
- 全片不超过 3 处文字；标题最后出现

## 3. 镜头契约

- 机位：平视或略俯，像人站在岸边看
- 运动：横移（看长卷）、缓慢推近、拉回整页；不要快速摇镜
- 焦点：整张纸都在焦内；靠颜色和密度引导视线，不靠虚化
- 转场：颜色到达 / 颜色退去 / 镜头拉回整页；不用叠化
- 节奏：每拍 8–14s；允许 1–2 处 1.5s 的静止

## 4. 声音契约

- 无旁白（默认）；若必须，用接近耳语的女声
- 配器：箫、古筝、低音弦、纸笔、水、风、木、铃
- 音乐：五声音阶，单主题，允许只出现一次完整旋律
- 拟音：笔尖摩擦、纸张翻动、水声、远处钟
- 留 1–2 处真静默（1s 以上），不要用底噪填满
- 全片 −14 LUFS，真峰值 ≤ −1.2 dB

## 5. 分镜模板（60s）

| 时间 | 画面 | 字幕 / 旁白 | 声音 |
|---|---|---|---|
| 0–8s | 空白纸角，笔尖写下时间地点，一条横线拉开河面 | 手写：三月·某地·夜 | 笔尖、纸 |
| 8–26s | 镜头上岸，白墙黑瓦石桥从线里长出来；一盏灯笼带来第一块颜色 | 无 | 箫进入、水声 |
| 26–42s | 灯笼穿过桥洞，记忆里的人显影；颜色第一次为“人”亮起 | 无 | 古筝、风 |
| 42–52s | 风起，颜色从她身上退去，只剩灯笼和月亮 | 无 | 弦乐收、静默 1s |
| 52–58s | 人走下桥，走进纸的下边距；镜头拉回整页 | 标题写出 | 铃、纸 |
| 58–60s | 朱红缩成河面一粒，定格 | 落款 | 余响 |

## 6. 风格提示词（可直接复制）

> 用钢笔淡彩的风格做一支 60 秒短片。整片是一张冷压水彩纸：先只有墨线，线有抖动、出头和断笔；白墙、黑瓦、石桥、乌篷船从线里慢慢长出来。一盏红灯笼带来第一块颜色，它经过哪里，淡彩就漫到哪里；颜色半透明、略微错位、有积色边。人物是 2D 剪影，12fps 轻微抖动，看不到五官。结尾颜色退回月亮和灯笼，镜头拉回整页，标题在空处写出。不要 3D，不要照片，不要满屏上色，不要快切。

## 7. 禁止项

- 3D 渲染、照片拼贴、AI 写实人像
- 颜色铺满全画面，或颜色早于线出现
- 矢量般光滑的线、完美对称的建筑
- 每拍都换镜头；快速摇镜、甩镜
- 整片字幕 / 大段旁白
- 引用受版权保护的原曲、原文、原画

## 8. 验收清单

- [ ] 开场 5 秒内只有线，没有颜色
- [ ] 颜色只跟着“那件事”走，退场有过程，不是硬切
- [ ] 线有抖动/出头/断笔，近看不是矢量
- [ ] 人物没有五官，boil 在 12fps 左右
- [ ] 留白 ≥35%，下边距明显宽于上边距
- [ ] 全片文字 ≤3 处，且小于最小建筑构件
- [ ] 有 1 处 ≥1s 的真静默
- [ ] 若借真实作品意象，版权说明已写进 `sources.md`
